# Lexer en Java
Elaborador por Jerónimo Arango Henao, Jerónimo Espinal Achury y Miguel Vallejo Duque

Para ejecutar el lexer, simplemente debe correrse el archivo Main.java e ingresar texto en la terminal. El REPL leerá el texto y lo convertirá en tókens de acuerdo con las reglas establecidas por el lexer
